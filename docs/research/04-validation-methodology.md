# Step 4：因子有效性分析與科學化驗證系統

> 本文件定義網站上「每一個數字怎麼算、什麼條件下可以貼什麼標籤」。
> 原則：**網站不轉述作者聲稱的報酬率當結論**；文獻數字與自行重算數字永遠分欄顯示。

## 0. 證據標籤系統（全站統一）

| 標籤 | 意義 | 顯示規則 |
|---|---|---|
| `文獻實證` | 論文原始報告的結果（市場、期間、方法以論文為準） | 必附論文連結、表格位置（如 Table 2）、樣本期間 |
| `自行回測` | 本平台用自己的資料與程式重算 | 必附：資料源、股票池、期間、成本假設、試驗次數 N、程式版本 |
| `尚未驗證` | 公式已收錄，尚未重算 | 不顯示任何績效數字，只顯示公式與文獻 |
| `示範資料` | 合成/隨機資料，只為展示介面 | 圖表加浮水印；不得出現在排行榜或比較頁的「研究結果」區 |

`自行回測` 再細分驗證等級（只能逐級往上升，每級條件見第 6 節）：

```
L0 尚未驗證 → L1 樣本內顯著 → L2 樣本外確認 → L3 扣成本後有效 → L4 跨市場/跨期間穩健
```

一個因子可以同時是「`文獻實證`（美股 1963–1990）」與「`自行回測` L1（台股 2010–2025）」，兩者分開呈現，不合併成一個分數。

## 1. 資料前處理（所有指標的前提）

不先處理這些，後面的 IC、Sharpe 都沒有意義。

| 問題 | 處理規則 |
|---|---|
| **未來資料洩漏（Look-ahead）** | 訊號只能用 t 日收盤（含）以前「當時已公開」的資料；交易在 t+1 執行（預設 t+1 收盤價成交，可選 t+1 開盤）。前瞻報酬 $r_{i,t\to t+h}$ 從 t+1 起算。 |
| **財報可得時間（Point-in-Time）** | 會計資料以「公告日」生效，不以「財報期末日」生效。台股：無逐筆公告日時，用法定截止日保守落後——年報 3/31、Q1 5/15、Q2 8/14、Q3 11/14；**月營收**每月 10 日前公告（以 10 日後生效）。美股：用 SEC EDGAR 的 filing date；無則年報落後 90 天、季報落後 45 天（保守）。重編/更正財報只能用「當時版本」，無版本資料時在因子頁註明此偏誤。**免費台股來源（FinMind）財報只有期末日、沒有公告日**，用它時一律套法定期限，並在結果標「PIT 為估計」。 |
| **公司行動** | 報酬一律用含息還原（total return）價格；股票分割、減資、現金增資、配股以還原因子處理。價格類過濾條件（如股價 < 10 元剔除）用**未還原**收盤價，避免還原價造成的人為過濾。 |
| **存活者偏誤** | 股票池必須包含已下市股票（下市前最後報酬計入；美股文獻慣例：下市報酬缺漏時依 Shumway 1997 補 −30%，台股以最後交易價處理並註明）。免費來源（如 yfinance）通常缺下市股 → 該回測自動標註「可能有存活者偏誤」。 |
| **股票池** | 台股：上市＋上櫃普通股，排除 ETF、存託憑證、全額交割股、上市未滿 N 日（預設 60 交易日）；可選「市值前 200 / 前 500」。美股：NYSE/AMEX/NASDAQ 普通股（share code 10/11 概念），排除股價 < $5 與 NYSE 市值 20 分位以下的 microcap（Fama-French 慣例；可切換）。歷史成分以「當時」成分為準，不用今天的成分股回推。 |
| **缺漏值** | 因子值缺漏 → 該期不納入排序（不補 0、不補均值）；一個截面有效樣本 < 30 檔則該期 IC 記為缺漏。報告每期覆蓋率（coverage）。 |
| **異常值** | 每期截面做 winsorize（預設 1% / 99%）或 MAD 截尾（中位數 ± 5×MAD），再做截面 z-score：$z_{i,t} = (f_{i,t} - \bar f_t)/s_t$。 |
| **因子方向** | 資料庫每個因子定義 `direction ∈ {+1, −1}`：+1 表「值越大、預期報酬越高」。所有 IC 與分組都先乘上 direction，使「正 IC = 符合文獻方向」。方向在看資料前就固定，不可事後翻轉。 |
| **中性化（可選）** | 對產業虛擬變數與 $\ln(\text{市值})$ 做截面迴歸取殘差，回答「這個因子是不是只是小型股/某產業效應」。預設同時報告原始與中性化版本。 |

## 2. 因子有效性指標

記號：$f_{i,t}$ = 股票 $i$ 在 $t$ 期（方向調整後）的因子值；$r_{i,t\to t+h}$ = 從 t+1 起 $h$ 期的前瞻報酬；$N_t$ = 該期有效股票數；$T$ = 期數。

| 指標 | 計算方式 | 適用情境 | 限制 |
|---|---|---|---|
| **IC**（Pearson） | $IC_t = \mathrm{corr}(f_{\cdot,t},\ r_{\cdot,t\to t+h})$ | 因子值近似線性對應報酬時 | 對極端值敏感；需先 winsorize |
| **Rank IC**（Spearman） | $RankIC_t = \mathrm{corr}(\mathrm{rank}(f_{\cdot,t}),\ \mathrm{rank}(r_{\cdot,t\to t+h}))$ | **預設主指標**，排序選股只在乎相對順序 | 不反映報酬幅度；小 $N_t$ 時雜訊大 |
| **IC Mean** | $\overline{IC} = \frac1T\sum_t IC_t$ | 平均預測力；月頻 Rank IC 0.02–0.05 在實務上已算有意義 | 單看平均會掩蓋不穩定 |
| **IC Std** | $\sigma_{IC} = \sqrt{\frac{1}{T-1}\sum_t (IC_t-\overline{IC})^2}$ | 預測力的穩定度 | — |
| **ICIR** | $ICIR = \overline{IC}/\sigma_{IC}$；年化 $= ICIR\times\sqrt{P}$（$P$=每年期數） | 比較不同因子的「每單位不穩定性的預測力」 | 與 Sharpe 一樣受期數與自相關影響 |
| **IC t 值** | $t = \overline{IC}/(\hat\sigma_{NW}/\sqrt T)$，$\hat\sigma_{NW}$ 為 Newey-West 標準誤（lag = $h-1$） | 判斷顯著性；**持有期 > 調倉頻率造成重疊樣本時必須用 NW** | 多重檢定下 t=2 不夠，見第 4 節 |
| **IC 勝率** | $\frac1T\sum_t \mathbb 1[IC_t>0]$ | 直觀的一致性 | 不反映幅度；55% 勝率可能已顯著，也可能只是運氣（看 T） |
| **因子衰減** | 對 $h \in \{1,5,10,20,60,120\}$ 交易日分別算 $\overline{RankIC}(h)$，並算因子排名自相關 $\rho_k=\mathrm{corr}(\mathrm{rank} f_t, \mathrm{rank} f_{t-k})$ | 決定調倉頻率：IC 衰減快 → 需高頻調倉 → 成本高 | 長 $h$ 的 IC 有重疊樣本問題 |
| **分組報酬** | 每期依 $f$ 分 $Q$ 組（預設 5 組，股票少的台股中小型股池可用 3 組），算各組等權/市值權重下期報酬，再對時間平均；附各組累積報酬曲線 | 看是否**單調**：計算組號與平均報酬的 Spearman 相關作為單調性分數 | 分組邊界造成雜訊；等權結果常被小型股主導，必須同時報市值加權 |
| **多空報酬** | $LS_t = R^{Q_{top}}_t - R^{Q_{bottom}}_t$ | 學術慣例、衡量純因子溢酬 | **台股放空受限（券源、平盤下放空規定、借券成本）**→ 台股預設同時報「純做多頂組 vs 基準」的超額報酬，那才是可交易的版本 |
| **Fama-MacBeth（第二階段）** | 每期截面迴歸 $r_{i,t+1} = a_t + b_t f_{i,t} + c_t' X_{i,t} + e$，報 $\bar b$ 與 NW t 值 | 控制規模、B/M、動能等已知因子後，看是否還有**增量**解釋力 | 需要多因子資料齊全 |
| **因子換手** | $TO_t = \frac12\sum_i |w_{i,t} - w^{drift}_{i,t}|$ | 估算交易成本，與衰減一起看 | — |

## 3. 策略績效指標

$r_t$ = 策略每期淨報酬（**已扣成本**），$r_f$ = 無風險利率（台股：台銀一年期定存；美股：3 個月 T-bill；預設可設 0 但須註明），$P$ = 每年期數。

| 指標 | 計算方式 | 限制 |
|---|---|---|
| 累積報酬 | $NAV_T = \prod_t (1+r_t)$ | — |
| CAGR | $NAV_T^{\,P/T} - 1$ | 對起訖點非常敏感 |
| 年化波動 | $\sigma\sqrt P$ | 假設報酬 i.i.d. |
| Sharpe | $\frac{\overline{r - r_f}}{\sigma(r-r_f)}\sqrt P$ | 報酬非常態（負偏態、肥尾，例如動能崩盤）時高估；同時附 Sharpe 的標準誤 $\sqrt{(1 - \gamma_3 SR + \frac{\gamma_4-1}{4}SR^2)/(T-1)}$（Lo 2002；Mertens 2002） |
| Sortino | $\frac{\overline{r - MAR}}{DD}\sqrt P$，$DD = \sqrt{\frac1T\sum_t \min(0, r_t - MAR)^2}$ | 下方樣本少時不穩定 |
| 最大回撤 | $MDD = \max_t \left(1 - \frac{NAV_t}{\max_{s\le t} NAV_s}\right)$；附回撤期長度與恢復期 | 單一路徑統計，樣本依賴性高 |
| Calmar | $CAGR / MDD$ | 同上，期間短時無意義（建議 ≥ 3 年） |
| 勝率 | 正報酬期數 / 總期數；交易層級則為獲利交易 / 總交易 | 不含盈虧比，單獨看會誤導 |
| 換手率 | 年化單邊換手 $= \frac{P}{T}\sum_t TO_t$ | — |
| 交易成本 | 見下表；**所有績效預設為扣成本後**，另附未扣成本版本做對照 | 衝擊成本對小型股會被低估 |
| 基準比較 | 超額報酬、$\alpha,\beta$（對基準迴歸）、追蹤誤差、Information Ratio | 基準選錯會讓 alpha 失真 |

**交易成本預設**（使用者可在回測頁調整）：

| 市場 | 買進 | 賣出 | 滑價預設 | 放空 |
|---|---|---|---|---|
| 台股 | 手續費 0.1425%（可設折扣） | 手續費 0.1425% ＋ 證交稅 0.3%（ETF 0.1%） | 大型 5 bps／中小型 20–50 bps | 預設不放空；開啟時加借券費（預設年化 1–3%）並提示券源限制 |
| 美股 | 佣金 0（可設） | 佣金 0 ＋ SEC/FINRA 規費（極小） | 依市值 5–30 bps | 借券費預設年化 0.3%，難借券另計 |

> 台股來回約 0.585%（未折扣）＋滑價：月換手 100% 的策略一年成本可達 7% 以上。**高換手的短期反轉、成交量類因子在台股特別容易被成本吃光**，網站要把「扣成本前 vs 後」並排顯示。

**基準**：台股用發行量加權股價**報酬**指數（含息）或 0050；美股用 SPY 或全市場市值加權；另附「股票池等權」基準，用來區分「選股能力」與「等權/小型股傾斜」。

## 4. 統計可靠性

### 4.1 樣本內／樣本外
- **時間切分**：預設樣本內 = 前 60% 期間，樣本外 = 後 40%；**參數、方向、門檻一律只能在樣本內決定**。
- **發表後檢驗**（文獻因子特有、最有說服力）：以論文發表年（或 SSRN 首次上線年）為切點，比較發表前後表現（McLean & Pontiff 2016 方法）。
- **跨市場樣本外**：美股論文發現的因子拿到台股測，本身就是一種樣本外。

### 4.2 Walk-Forward 驗證
- 對有參數或需要訓練的因子（ML、多因子權重），用滾動或擴張視窗：每次用過去 $W$ 期訓練/選參數，測下一段 $S$ 期，串接所有測試段得到樣本外績效。
- 標籤（前瞻報酬）重疊時，訓練集與測試集之間做 **purging（剔除重疊標籤）與 embargo（間隔期）**（López de Prado 2018 方法）。

### 4.3 不同市場期間
- 台股/美股各自切出事件期：2000–02 網路泡沫、2008–09 金融海嘯、2015–16（台股）、2020 COVID、2022 升息熊市。
- 以市場狀態分組：多頭/空頭（基準 12 個月報酬正負）、高/低波動（VIX 或台指 VIX 中位數上下）。
- 以市值分組：大型股 vs 小型股（很多異象只存在小型股，可交易性低）。

### 4.4 因子穩定性
- 12 個月滾動 Rank IC 圖；年度 IC 為正的比例。
- 參數敏感度熱力圖（如動能形成期 3/6/9/12 × 跳過期 0/1）：**表現只在一個尖銳參數點成立 → 過擬合警訊**。

### 4.5 多重假設檢定（Data Snooping）
- 平台**記錄每個因子被回測的次數（含所有參數組合）**，即試驗次數 $N$，在結果頁顯示。
- 顯著性門檻：依 Harvey, Liu & Zhu (2016)，新因子建議 $t > 3.0$；同時提供 Holm／BHY 調整後 p 值。
- **Deflated Sharpe Ratio**（Bailey & López de Prado 2014）：
  $$DSR = \Phi\!\left(\frac{(\widehat{SR} - SR_0)\sqrt{T-1}}{\sqrt{1 - \hat\gamma_3\widehat{SR} + \frac{\hat\gamma_4 - 1}{4}\widehat{SR}^2}}\right),\quad SR_0 = \sqrt{V[\{\widehat{SR}_n\}]}\left((1-\gamma)\Phi^{-1}\!\left(1-\tfrac1N\right) + \gamma\,\Phi^{-1}\!\left(1-\tfrac1{Ne}\right)\right)$$
  其中 $\hat\gamma_3$ 偏態、$\hat\gamma_4$ 峰度（非超額）、$\gamma \approx 0.5772$（Euler-Mascheroni）、$V[\{\widehat{SR}_n\}]$ 為 N 次試驗 Sharpe 的變異數（Sharpe 皆為每期、非年化）。DSR < 0.95 → 不得升級到 L3。
- 第二階段可加 **PBO（Probability of Backtest Overfitting，CSCV 法）**。

### 4.6 偏誤檢查清單（每次回測自動產生）
| 偏誤 | 自動檢查 |
|---|---|
| Survivorship | 股票池是否含下市股？否 → 加警示 |
| Look-ahead | 財報欄位是否有公告日？無 → 是否套用法定落後？訊號與成交是否至少差 1 期？ |
| Data snooping | 顯示試驗次數 N、DSR |
| 過擬合 | 參數數量、樣本外/樣本內 Sharpe 比值（< 0.5 警示）、參數敏感度 |
| 小樣本 | 期數 < 36 個月、平均截面股票數 < 100 → 警示 |

## 5. 回測引擎（MVP 用向量化截面回測）

```
for 每個調倉日 t（依調倉頻率）:
    1. 取 t 日收盤前已公開的資料 → 計算因子值 f_{i,t}（PIT）
    2. 過濾股票池（當時成分、流動性、價格門檻）
    3. 前處理：winsorize → z-score →（可選）中性化 → 乘 direction
    4. 多因子：加權 z-score 合成 S_i = Σ_k w_k z_{i,k}
    5. 目標權重：頂組等權 / 市值權 / 分數權重；設單檔上限
    6. 以 t+1 價格成交；成本 = Σ|Δw| × 單邊成本（買賣分開計，含證交稅）
    7. 持有到下一調倉日，期間權重隨價格漂移
```

IC 分析與策略回測**共用同一份 PIT 因子矩陣**，避免兩邊口徑不一致。

## 6. 驗證等級的升級標準

| 等級 | 條件（全部滿足） |
|---|---|
| L1 樣本內顯著 | 樣本內 Rank IC 均值方向正確，NW $t \ge 2$；分組單調性分數 ≥ 0.7；覆蓋率 ≥ 70% |
| L2 樣本外確認 | 樣本外 Rank IC 同方向、$t \ge 2$；樣本外/樣本內 IC 比 ≥ 0.5；**全期 $t \ge 3$**（HLZ 門檻） |
| L3 扣成本後有效 | 樣本外、扣成本後：可交易版本（台股做多頂組、美股可多空）相對基準的 IR > 0；DSR ≥ 0.95（以平台記錄的試驗次數計） |
| L4 跨市場/期間穩健 | 台股與美股都達 L2；≥ 60% 的年份 IC 為正；大型股子樣本仍顯著；參數敏感度無尖點 |

> 即使達 L4，網站也只陳述「歷史資料上的統計證據」，**不宣稱未來獲利**。

## 7. 台股 vs 美股：會影響因子結果的差異

| 面向 | 台股 | 美股 | 對因子的影響 |
|---|---|---|---|
| 股票數 | 上市約 1,000、上櫃約 800 | 數千檔 | 台股分組少（建議 5 組上限），IC 雜訊較大 |
| 權重集中 | 台積電占加權指數權重極高 | 相對分散 | 市值加權的台股結果幾乎由少數權值股決定，必須同時看等權 |
| 漲跌幅限制 | ±10%（2015-06 起；之前 ±7%） | 無 | 短期反轉/動能在漲跌停附近失真；漲跌停鎖死時無法成交 |
| 交易稅 | 賣出 0.3% | 無 | 高換手因子的淨績效差距很大 |
| 放空 | 融券/借券有限制與成本 | 相對容易 | 台股多空報酬可交易性低 |
| 投資人結構 | 散戶交易比重高 | 機構為主 | 反轉、注意力、成交量類異象可能更強，但也更不穩定 |
| 財報時程 | 法定截止日集中（3/31、5/15、8/14、11/14），**月營收**每月公告 | 依申報人規模分散 | 台股有獨有的「月營收動能」可研究；PIT 處理相對簡單 |
| 除權息 | 集中在 6–9 月 | 分散（季配為主） | 還原價處理錯誤會在這段期間產生大量假訊號 |
| 獨有資料 | 三大法人買賣超、融資融券餘額、集保股權分散 | 13F、空單比率 | 台股可延伸法人籌碼因子（需另找文獻支持，否則標 `尚未驗證`） |

## 8. 網站上每個數字的「出生證明」

每個圖表/指標卡在 hover 或底部顯示：資料源｜股票池與平均檔數｜期間（樣本內/外切點）｜調倉頻率｜成本假設｜試驗次數 N｜證據標籤｜程式版本（git commit）。
缺任何一項的數字不得進入「比較」頁或排行榜。
